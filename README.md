# 🌍 Life Expectancy Prediction using Machine Learning

## 📌 Problem Statement
Life expectancy varies significantly across countries due to socio-economic, healthcare, and demographic factors.  
This project aims to analyze these factors and build predictive models to estimate life expectancy.

---

## 🎯 Objectives
- Identify key factors influencing life expectancy
- Analyze impact of disease burden and economic indicators
- Compare multiple regression models
- Select best-performing model

---

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- XGBoost

---

## 📊 Models Implemented
- Linear Regression (R² = 0.82)
- Random Forest (R² = 0.968) ✅ Best Model
- XGBoost (R² = 0.959)

---

## 🔎 Key Insights
- HIV/AIDS prevalence is the strongest predictor of life expectancy
- Income composition significantly impacts outcomes
- Adult mortality strongly affects life expectancy
- Random Forest achieved highest predictive accuracy

---

## 📈 Project Workflow
1. Data Cleaning
2. Missing Value Handling
3. Feature Engineering
4. Exploratory Data Analysis
5. Model Building
6. Model Evaluation
7. Feature Importance Analysis

---

## 🚀 Conclusion
Disease burden and socio-economic development are major determinants of life expectancy.  
Random Forest provided the most accurate predictions among tested models.
